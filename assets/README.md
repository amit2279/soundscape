# Assets for the runner world

Drop 3D files here. Format: **GLB** (glTF binary), low-poly or stylized, ideally one matching style.
Aim for under ~20,000 triangles per character and a few MB per file.

## hero/
One rigged character, with these animation clips (in one GLB, or one GLB per clip on the same skeleton):
- run
- sword slash (2 or 3 variations)
- punch
- kick
- dodge or roll
- get hit
- jump

## creatures/
Two to four rigged creatures: one small and fast, one big and heavy, one boss. Each needs:
- run or charge
- attack
- get hit
- die

## props/
- a sword
- a handful each of rocks, cliffs, trees, grass tufts, ruins

## sky/ (optional)
- one day sky image, one night sky image
